# ExtendPad for Windows 1.2.2

This release introduces the complete Windows companion for ExtendPad.

## Highlights

- One installer includes the Windows app and virtual-display component.
- One-click setup for a true extended Windows desktop.
- Mirror and Extend modes.
- Native display sizes for recent iPad models, including 2752×2064 for the 13-inch iPad Pro.
- Automatic resolution matching after the iPad connects.
- Place the iPad to the left, right, above, or below the primary monitor.
- Adjustable frame rate and image quality.
- Touch input forwarding and connection recovery improvements.

## Requirements

- 64-bit Windows 10 or Windows 11
- Administrator approval during the first Extend-mode setup
- PC and iPad on the same trusted local network
