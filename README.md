# ExtendPad for Windows

ExtendPad turns an iPad into a wireless second display for a Windows PC.

## Download

[Download the latest Windows installer](https://github.com/frankfu0714-cyber/extendpad-downloads/releases/latest)

## Requirements

- 64-bit Windows 10 or Windows 11
- An iPad with the ExtendPad app
- Both devices connected to the same trusted local network
- Administrator approval during the first Extend-mode setup

## Quick start

1. Download and run the Windows installer.
2. Open ExtendPad on Windows and on the iPad.
3. Connect using the address shown in the Windows app.
4. Choose **Mirror** or **Extend your desktop**.
5. For Extend mode, approve the one-time display-component setup.
6. Select **Start Streaming**.

The Windows installer includes the virtual-display component. No separate driver app is required.

## Windows security notice

The current installer is not yet code-signed with an ExtendPad publisher certificate, so Microsoft Defender SmartScreen may display an **Unknown publisher** warning. Download ExtendPad only from this official repository and verify the SHA-256 checksum published with each release.

## Privacy

ExtendPad streams directly between the PC and iPad over the local network. Use it only on a network you trust. See the [ExtendPad privacy policy](https://frankfu0714-cyber.github.io/extendpad-privacy/).
